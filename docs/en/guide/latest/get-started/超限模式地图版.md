# 超限模式地图版

适合从零开始制作地图，或希望直接使用完整的演出、任务、场景、存档和调试模块的项目。导入后，在这份模板地图上继续开发。

视频参考：[2.0 完整教程 03:42—04:45](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=222)。

[返回模板选择](./get-started.md)

## 1. 下载地图资产

打开[奇域资产中心：超限模式地图版](https://act.mihoyo.com/ys/prod/ugc/component-store/index.html#/item/1992801772275511296)，下载地图版资产。

::: warning 已有项目如何选择
地图版会导入为一份独立地图。已有大量搭建内容、需要给原地图接入演出的项目，先查看[超限模式元件版导入](./超限模式元件版.md)。不要把旧地图的全部数据重新导入新版模板来尝试覆盖迁移。
:::

## 2. 导入 GIL 地图存档

1. 解压上一步下载的地图版资产。
2. 找到资产中的 `.gil` 地图存档。
3. 回到游戏的「我的奇域」，选择「导入存档」，选中该 `.gil`。
4. 打开导入后的模板地图，先试玩现成示例，确认对话、任务等功能能够运行。
5. 在这份模板地图上继续开发。地图版已经配置了模板所需的玩家模板、脚本和索引，无须照着元件版的步骤再修一次。

::: tip 地图版已完成模板初始化
地图版已经配置演出玩家模板、脚本、UI 索引和模板多语言文本，无须重复元件版的修复步骤。先试玩模板示例，确认能正常运行，再开始修改。
:::

## 3. 配置网页工作区

打开[在线编辑器](https://tool.xiaomol444.xyz/DSFGStudio)，新建工作区。在「工作区设置」中核对：

| 设置 | 应如何填写 |
| --- | --- |
| 项目文件类型 | 选择「超限模式地图版」 |
| 基准版本 | 选择实际使用的模板版本；2.0 对应原神 7.1，2.1 对应原神 7.2 |
| 已安装扩展包 | 只启用地图中已安装的扩展包。2.1 基准自带 7.2 技能动画扩展包 |
| 结构体 ID 与技能配置 ID | 用「读取 GIL」读取自己的地图存档，核对识别结果后保存 |

「读取 GIL」用于识别导出目标，「读取 GIL 并修复」用于修复存档里的 UI 索引，两者用途不同。导入新元件或技能后，配置 ID 可能变化，需要重新读取校对。

完成后，确认目标玩家使用正确模板、界面文字正常、工作区类型和基准版本一致。接下来前往[创建对话](../功能介绍/创建对话.md)。
