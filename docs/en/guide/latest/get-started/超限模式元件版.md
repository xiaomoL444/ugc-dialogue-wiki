# 超限模式元件版

适合在已经制作的超限模式地图中接入演出、镜头和技能动作。该元件不附带地图版的任务、场景、存档和调试模块。

视频参考：[2.0 导入教程 04:45](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=285)，自动修复索引另见 [2.1 更新视频 07:53](https://www.bilibili.com/video/BV19W4v6oE3L/?t=473)。

[返回模板选择](./get-started.md)

## 1. 下载元件资产

打开[奇域资产中心：超限模式元件版](https://act.mihoyo.com/ys/prod/ugc/component-store/index.html#/item/1992936426160795648)，下载对应资产。

::: warning 导入前先备份
先备份自己的地图存档。元件转存不会覆盖更新已有节点图，不要反复导入整套模板来升级，旧项目的更新方式见[版本与升级](../版本与升级.md)。
:::

## 2. 转存元件资产

1. 解压上一步下载的资产，找到其中的 `.gia` 文件。
2. 在自己的地图内打开「资产导入导出管理」，点击「加载外部资产」并「打开目录」。
3. 将 `.gia` 复制到打开的外部资产目录。
4. 回到游戏，再次「加载外部资产」，选中模板资产包，点击「转存所选资产」。
5. 选择导入目标页签并确认。可以把导入页签改名为「演出模板」，方便区分自己原来的资产。

::: important 元件导入后还没有配置完成
继续完成下方的玩家模板、索引修复和多语言文本导入。只导入 `.gia` 就开始播放，可能出现没有 UI、按钮无效或界面显示文本键名等问题。
:::

## 3. 应用演出玩家模板

进入「战斗预设 → 玩家模板」，找到导入的「演出模板」，将它应用到需要使用演出的玩家。

这个模板承载演出所需的自定义变量和节点图。已有自定义玩家模板的项目，也可以自行迁移这些变量和节点图，但要完整保留依赖；首次接入建议先使用模板自带的玩家模板验证。

![将演出模板应用到玩家](/images/tutorial-v2/player-template.jpg)

*图：视频 [05:37](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=337)，玩家模板设置。*

## 4. 自动修复 UI 索引

元件转存后，UI 索引会发生变化。当前编辑器已经支持直接修复导出的地图存档：

1. 将已经导入元件的地图导出为 `.gil`。
2. 打开[对话模板编辑器](https://tool.xiaomol444.xyz/DSFGStudio)，进入「工作区设置」。旧布局的入口是工作区右侧「…」。
3. 在「自动修复索引」中点击「读取 GIL 并修复」（部分版本显示为「读取并修复」）。
4. 选择刚导出的地图存档，检查处理结果，下载修复后的新存档。
5. 在「我的奇域」中导入这份新 `.gil`，进入新存档继续制作；确认演出玩家模板仍应用到了目标玩家。

修复后导入的是**完整地图存档**。进入修复后的新存档继续制作，修复前的原存档保留作备份。

![当前在线编辑器的工作区设置，包含 GIL 识别与索引修复入口](/images/tutorial-v2/workspace-settings-current.jpg)

*图：在线编辑器于 2026-11-10 的工作区设置。基准版本请按自己的模板选择，截图中的默认值不是统一要求。*

### 手动核对索引（可选）

2.0 视频 [05:35—06:09](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=335) 演示了旧的手动方法：从界面控件组找到「确认提示」和「对话 UI」的实际索引，再修改五个客户端脚本的对应索引变量。

五个脚本为 `Black_Screen_Script`、`Dialog_Bottom_CG`、`Bottom_Dialog_Script`、`Dialogue_Default_UI_Script`，以及 `Message_Dialog/styles/Default.lua`。不同版本的显示名称可能稍有差异，应核对完整路径和变量用途。

![手动修复脚本中的 UI 索引变量](/images/tutorial-v2/manual-ui-index.jpg)

*图：视频 [06:05](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=365)。索引以自己存档内的值为准，不要照抄画面中的整数。*

## 5. 导入多语言文本

1. 在网页编辑器左上角打开菜单，进入「多语言文本」管理。
2. 下载模板的语言文件，例如简体中文文件。
3. 回到千星沙箱，打开「多文本管理（脚本变量）」。
4. 导入刚下载的语言文件。已有多语言内容的项目，先导出备份，再把模板文本合并到自己的文件中导入，保留原有条目。
5. 试玩，检查自动播放、历史对话、隐藏 UI 等按钮是否显示正常文字。

![在网页编辑器中下载模板多语言文本](/images/tutorial-v2/multilingual-text.jpg)

*图：视频 [06:30](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=390)。自动修复索引不会代替多语言文本导入。*

## 6. 配置网页工作区

打开[在线编辑器](https://tool.xiaomol444.xyz/DSFGStudio)，新建工作区。在「工作区设置」中核对：

| 设置 | 应如何填写 |
| --- | --- |
| 项目文件类型 | 选择「超限模式元件版」 |
| 基准版本 | 选择实际使用的模板版本；2.0 对应原神 7.1，2.1 对应原神 7.2 |
| 已安装扩展包 | 只启用地图中已安装的扩展包。2.1 基准自带 7.2 技能动画扩展包 |
| 结构体 ID 与技能配置 ID | 用「读取 GIL」读取自己的地图存档，核对识别结果后保存 |

「读取 GIL」用于识别导出目标，「读取 GIL 并修复」用于修复存档里的 UI 索引，两者用途不同。导入新元件或技能后，配置 ID 可能变化，需要重新读取校对。

完成后，确认目标玩家使用正确模板、界面文字正常、工作区类型和基准版本一致。接下来前往[创建对话](../功能介绍/创建对话.md)。
