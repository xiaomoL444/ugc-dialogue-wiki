# 下载与导入

先了解三种模板的用途和区别，再选择对应的下载与导入教程。

三种模板的基础演出用法相同，包含的模块和导入步骤不同。

## 三种模板有什么区别

| 模板 | 适合的项目 | 包含的主要内容 | 导入形式 |
| --- | --- | --- | --- |
| 超限模式地图版（推荐） | 从模板开始制作新地图 | 演出、镜头、技能动作，以及任务、场景、存档和调试模块 | 导入 `.gil`，得到一份完整模板地图 |
| 超限模式元件版 | 已有超限模式地图，需要接入演出 | 演出、镜头与技能动作，不包含地图版的任务、场景、存档和调试模块 | 将 `.gia` 资产转存到自己的地图，再完成初始化 |
| 经典模式元件版 | 已有经典模式地图，需要接入对话演出 | 2.1 已增加经典模式支持；需要获取玩家镜头数据的操作仍受限，不包含地图版模块 | 将经典模式 `.gia` 转存到自己的地图，再完成初始化 |

## 超限模式地图版

地图版是一份已配置好各模块的完整地图。下载并导入后，就可以先试玩示例，再在这份地图上继续开发。它适合刚开始制作项目，或需要完整 RPG 基础模块的情况。

地图版已经配置玩家模板、UI 索引和模板多语言文本，导入步骤相对简单。

[查看超限模式地图版下载与导入教程 →](./超限模式地图版.md)

## 超限模式元件版

元件版用于给自己的超限模式地图接入演出系统，适合已经完成大量场景搭建、不方便换地图的项目。

它提供演出、镜头与技能动作，但不附带地图版的任务、场景、存档和调试模块。转存资产后，还需要应用演出玩家模板、修复 UI 索引并导入多语言文本。

[查看超限模式元件版下载与导入教程 →](./超限模式元件版.md)

## 经典模式元件版

经典模式地图应选择对应的经典模式元件资产。2.1 已增加经典模式支持，但仍不支持需要获取玩家镜头数据的操作，不能直接照搬超限模式的所有镜头设置。

导入后，同样需要完成玩家模板、索引和多语言文本配置，并在网页工作区选择经典模式元件版与实际模板基准。

[查看经典模式元件版下载与导入教程 →](./经典模式元件版.md)

## 选择下载与导入方法

1. **准备新建超限模式项目**：[超限模式地图版](./超限模式地图版.md)。
2. **已有超限模式地图，接入演出功能**：[超限模式元件版](./超限模式元件版.md)。
3. **在经典模式地图中制作对话**：[经典模式元件版](./经典模式元件版.md)。

::: warning 已有模板项目先确认版本
不要通过反复导入整套模板资产来覆盖更新已有项目，也不要把旧地图的全部数据重新导入新版地图。升级已有模板请先阅读[版本与升级](../版本与升级.md)。
:::

完成所选教程中的导入与工作区配置后，继续阅读[创建对话](../功能介绍/创建对话.md)。
