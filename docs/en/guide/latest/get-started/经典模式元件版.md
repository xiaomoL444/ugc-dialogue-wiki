# 经典模式元件版

适合在经典模式地图中接入对话演出。使用支持经典模式的 2.1 模板；经典模式仍不支持需要获取玩家镜头数据的操作，详见[版本与升级](../版本与升级.md)。该元件不附带地图版的任务、场景、存档和调试模块。

视频参考：[2.1 更新视频 07:40](https://www.bilibili.com/video/BV19W4v6oE3L/?t=460)。其中 [07:53](https://www.bilibili.com/video/BV19W4v6oE3L/?t=473) 使用经典模式元件版演示自动修复索引。

[返回模板选择](./get-started.md)

## 1. 下载元件资产

打开[奇域资产中心：经典模式元件版](https://act.mihoyo.com/ys/prod/ugc/component-store/index.html#/item/2011262075678007296)，下载对应资产。

::: warning 导入前先备份
先备份自己的地图存档。元件转存不会覆盖更新已有节点图，不要反复导入整套模板来升级，旧项目的更新方式见[版本与升级](../版本与升级.md)。
:::

## 2. 参考超限模式元件版完成导入

::: tip 导入步骤相同
经典模式元件版的资产转存、玩家模板配置、UI 索引修复和多语言文本导入，与超限模式元件版相同。

下载本页的经典模式资产后，请从[超限模式元件版教程的「转存元件资产」](./超限模式元件版.md#_2-转存元件资产)开始，完成后续操作。

配置网页工作区时，「项目文件类型」仍选择 **经典模式元件版**，基准版本选择自己实际使用的经典模式模板（2.1 对应原神 7.2）。
:::

导入和工作区配置完成后，继续阅读[创建对话](../功能介绍/创建对话.md)。
