# 版本与升级

本 Wiki 的基础教程来自 [2.0 完整视频](https://www.bilibili.com/video/BV1ZCng6LEKV/)，同时补充 [2.1 更新视频](https://www.bilibili.com/video/BV19W4v6oE3L/)中的修复和兼容说明。

## 先确认三个版本概念

| 概念 | 意义 |
| --- | --- |
| 游戏版本 | 例如原神 7.1、7.2，决定可用的游戏功能与动作资源 |
| 模板基准版本 | 例如模板 2.0、2.1，决定实际拥有的节点图逻辑 |
| 网页编辑器设置 | 按实际模板选择文件类型、基准版本与扩展包，控制可编辑和导出的内容 |

2.0 对应原神 7.1 基准，2.1 对应原神 7.2 基准。**修改网页里的版本设置，不会升级游戏存档中的节点图。**旧工作区也不应直接按“最新”勾选全部功能。

模板的内部版本可能因修复继续变化，下载时结合资产说明和[更新日志](./更新日志.md)确认。

## 经典模式

2.0 视频中经典模式元件版仍处于等待更新的状态，2.1 已增加支持。经典模式不支持需要获取玩家镜头数据的操作。

选择经典模式元件版时，在工作区同步选择对应文件类型。地图版的任务、场景、存档、调试模块也不会因为切换工作区类型而自动出现在元件版中。

## 已有项目如何更新

升级前备份自己的地图和客户端脚本。把新模板导入为另一份独立地图，作为脚本与节点图的对照来源；不要把整套 `.gia` 反复转存进已有项目来尝试覆盖更新。

| 变更类型 | 更新方式 |
| --- | --- |
| 客户端脚本修复 | 从新版模板复制对应脚本目录，合并或覆盖到原项目 |
| 节点图逻辑修复 | 按更新视频修改原图；覆盖 Lua 不会完成这部分 |
| 新技能动画资源 | 导入技能扩展包，并重新校对配置 ID |
| 网页工作区设置 | 反映地图实际支持的版本和资源，不代替上述更新 |

### 更新客户端脚本

2.1 视频 [01:22—02:13](https://www.bilibili.com/video/BV19W4v6oE3L/?t=82) 演示了完整复制方式：

1. 下载最新地图版模板，导入为独立存档。
2. 进入千星沙箱的客户端脚本管理器，右键脚本，打开所在目录，再回到脚本根目录。
3. 复制整个新版脚本目录中的文件，保留原有目录层级。
4. 打开自己的旧项目，用同样方式找到脚本目录。
5. 地图版更新到原脚本根目录；元件版则进入根目录下的 `default_import_file` 文件夹后更新。
6. 如果自行改过样式或脚本，先合并自己的修改，再重新试玩。

脚本修复包括移动端自动播放、历史对话、隐藏 UI 按钮无法点击，以及部分传送后鼠标无法关闭的问题。它**不能单独修复**所有 UI 重建、镜头或任务节点图问题。

## 2.1 需要特别留意的修复

### 传送、死亡与 UI 重建

视频 [02:22—03:17](https://www.bilibili.com/video/BV19W4v6oE3L/?t=142)：2.0 在传送界面、角色死亡等情况下可能卡住且不显示 UI。覆盖脚本可以修复部分鼠标状态，但 UI 无法重新显示的问题涉及节点图。

2.1 使用「UI 重建」复合节点统一处理相关情况，并移除了原有单独的断线重连脚本／节点逻辑。2.0 继续开发时，演出内传送优先使用公共事件的「玩家传送」，并避免在演出期间触发角色死亡或意外传送；不要把“已更新 Lua”当成“已具备 2.1 重建逻辑”。

### 实体注册表字典类型

视频 [03:18—03:31](https://www.bilibili.com/video/BV19W4v6oE3L/?t=198)：在玩家模板上检查实体注册表对应的字典变量，字典值类型应为「实体」。旧版设置错误会让实体键值无法正常使用。

### 固定位置镜头

视频 [03:31—04:52](https://www.bilibili.com/video/BV19W4v6oE3L/?t=211)：在运镜管理器节点图中修正定位实体过早销毁及定时器逻辑。视频示范把相应定时器的 `0.03` 秒改为 `0.12` 秒，并调整连线和位置输入。

这里需要按视频核对完整节点位置和连线，不能只把所有同值定时器统一替换。修复后的镜头有约 0.12 秒前摇；网页也移除了旧固定位置的两个入口，类似需求改用「跟随」。

### 对话期间隐藏“查看任务”按钮

视频 [04:52—05:20](https://www.bilibili.com/video/BV19W4v6oE3L/?t=292)：地图版任务节点图中的「添加 UI」复合节点曾引用错误索引。用当前存档「查看任务」按钮的实际索引替换，再保存并重新试玩。

## 安装 7.2 技能动画扩展包

2.1 视频 [05:22—07:15](https://www.bilibili.com/video/BV19W4v6oE3L/?t=322)：

1. 旧模板项目从资产中心下载作者提供的技能动画扩展包，导入自己的地图。
2. 在网页「工作区设置」中保留旧模板的实际基准版本，并勾选「7.2 技能动画扩展包」。
3. 重新导出自己的地图 GIL，在工作区中读取，校对技能配置 ID。
4. 再从公共事件的技能列表选择新增动作。

最新 2.1 模板已自带该包，网页会随基准自动启用。「玩家朝向实体」属于新增节点图功能，不能只通过这个资源包获得。

扩展包请从作者资产页面或更新视频入口获取；本页不猜测未核对的独立资产链接。

## 其他设置调整

2.1 的地图版默认关闭「超出范围不运行」，相关演出实体也关闭了对应负载优化，场景范围默认设为 `1000 × 1000 × 1000`。旧项目可结合自身地图规模检查这些设置，避免管理实体离开运行范围。

2.1 还调整了移动端全屏下一句按钮、历史对话界面的比例适配，并增加公共事件 Clip 边缘拖拽开关。完整历史记录见[更新日志](./更新日志.md)，未发布的计划不视为当前可用功能。
