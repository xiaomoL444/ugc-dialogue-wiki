# 任务系统

2.x 的任务模块包含章节、主任务、子任务、后续任务和失败回溯，并通过任务单位状态接入游戏逻辑。**任务配置、接取流程与完成条件需要一起设置。**

该模块随**超限模式地图版**提供，元件版不附带。视频对应：[21:45—26:06](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=1305)。

## 1. 建立任务层级

在网页编辑器切换到「任务」。一个工作区维护一份任务配置，在其中编排多个章节、主任务和子任务。

| 层级 | 作用 | 示例 |
| --- | --- | --- |
| 章节 | 组织一组主任务；主任务也可以不归属章节 | 第一章：初到城镇 |
| 主任务 | 玩家在任务页面看到的一条主要任务 | 城镇的委托 |
| 子任务 | 真正接取、推进和完成的步骤 | 与向导交谈 → 收集材料 → 返回交付 |

章节、主任务、子任务各有自己的 ID。后续任务引用的是**完整子任务 ID**，不是它在列表中的位置，也不是主任务 ID。

## 2. 配置子任务

![子任务的参数与后续任务配置](/images/tutorial-v2/quest-editor.jpg)

*图：视频 [22:56](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=1376)。*

| 配置项 | 作用 |
| --- | --- |
| 标题、描述 | 任务追踪与任务页面显示的文本 |
| 所属主任务 | 决定任务归属，主任务再关联章节 |
| 任务单位状态 | 对应游戏中的单位状态配置，用它编写这一步的逻辑 |
| 调查点 | 任务目标的坐标 |
| 所属一级区域 | 与场景模块关联，用于区域提示与追踪判断 |
| 调查点范围 | 视频中负值表示以距离提示为主；需要区域内提示时配置有效范围 |
| 地图指引、指引特效 | 分别控制任务指引表现 |
| 隐藏任务 | 用于后台条件或任务流转；不能只以是否显示判断它是否在运行 |
| 后续任务 | 当前任务完成后接取的一个或多个子任务 |
| 失败回溯任务 | 失败后回到的子任务；无回溯时保留默认无关联状态 |
| 完成主任务 | 当前步骤结束时是否同时完成所属主任务 |
| 任务进度 | 供运行逻辑使用的进度值；阈值与含义由自己实现的任务逻辑约定 |

示例：把「与向导交谈」的后续任务设为「收集材料」，把「收集材料」的后续任务设为「返回交付」，最后一步开启「完成主任务」。需要失败重试时，再给相应步骤配置失败回溯。

一个任务可以接出多个后续任务，并非只能单线推进。隐藏子任务也可以用于管理并行条件，但完成与汇总条件需要自己通过单位状态逻辑明确实现。

## 3. 导出到地图任务配置

1. 点击「导出千星任务」，下载任务配置 JSON。
2. 在模板地图中找到任务管理实体及其任务配置变量。模板使用 `NOLOC_任务配置数据` 读取这份配置，保持原变量名和读取链路一致。
3. 将 JSON 导入对应的 `[任务]任务配置数据` 结构体变量并保存。
4. 如果结构体不匹配，先读取本地图 GIL 校对工作区的任务结构体 ID。

当前导出是一份包含章节、主任务和子任务的配置，不要按旧教程拆成三个互不关联的变量。

## 4. 接取、完成与失败

通过模板提供的任务复合节点，在需要的时机接取、完成或使任务失败。传入对应玩家和子任务 ID。

![模板的任务相关执行节点](/images/tutorial-v2/quest-nodes.jpg)

*图：视频 [23:50](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=1430)。实际节点名以所用模板为准。*

接取第一步后，让后续关联推动任务流程。不要用旧版“重复接取另一条任务就覆盖原任务”的方式代替完整任务流转。

## 5. 为任务制作单位状态

任务的具体玩法通过单位状态实现。例如收集材料任务，可以在状态运行期间监听玩家获得物品，达到约定数量后完成当前子任务。

1. 在战斗预设中创建对应的单位状态，并准备它使用的节点图。
2. 参考模板已有任务单位状态，接入任务初始化、进度与完成／失败逻辑。
3. 把该单位状态的实际配置 ID 填回网页子任务。
4. 完成、失败和读档恢复时，检查事件监听、进度与状态清理是否符合预期。

![为任务步骤创建单位状态](/images/tutorial-v2/quest-unit-state.jpg)

*图：视频 [25:10](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=1510)。*

给任务设置一个进度值不会自动产生收集玩法；任务配置描述流程，单位状态实现完成条件。

## 区域与追踪

任务的「所属一级区域」需要引用[场景管理](./场景管理.md)中实际存在的一级区域。跨世界任务还需要配置世界之间的关联点，才能给玩家正确的前往提示。

![为任务选择所属一级区域](/images/tutorial-v2/scene-editor.jpg)

*图：视频 [27:10](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=1630)。*

任务不显示时，检查是否已接取、是否为隐藏任务、所属主任务和区域是否有效；不流转时，检查完成逻辑与后续 ID。

任务的存档容量与配置可容纳的任务数量是两个概念。默认存档最多保存 20 个已接任务及其进度，详见[存档功能](./存档功能.md)。
