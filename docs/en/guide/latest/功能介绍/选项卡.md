# 选项卡

演出中的选项卡用于让玩家选择回答，并进入对应的剧情路线。2.x 在编辑器中逐条添加选项，**每条选项通过自己的出口连接后续 Group**。

视频对应：[09:25 附近的选项演示](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=565)。

## 制作两个回答

例如，派蒙问「今天去哪里玩？」，玩家可选择「去城里」或「去野外」。

1. 在文本编辑视图中，选中提问的对话集合，添加选项卡。
2. 添加两条选项，分别填写「去城里」和「去野外」，按需要选择图标。
3. 分别创建后续对话：「那就去城里转转吧。」和「出发！我们去野外探险。」。
4. 从「选项 1」端口连接城里的路线，从「选项 2」端口连接野外的路线。
5. 检查「开始」能到达提问节点，再导出并更新游戏中的演出变量。

## 在时间轴中调整出现时机

切换「节点编辑」，选中包含选项的 Group，在时间轴中找到 Select 片段。它的开始时间决定选项何时出现。

同一 Group 中，普通对话与选项都可能请求流程出口。需要由选项决定走向时，不要再让同一段对话通过「玩家按下」抢先推进；按编辑器的冲突提示调整，通常将对话设为「不触发按下」，保留选项出口。

如果选项应在另一句之后单独出现，也可以放到后续 Group，避免不同推进方式混在一起。

## 共同收尾

两条路线可以各自结束，也可以连接到同一个收尾 Group。例如两个选择先各播一句回应，再都连接到「我们出发吧」。合流由连线表达，不需要再创建旧版的「跳转对话变量」。

## 测试重点

- 两个选项都实际点一次，确认进入的是对应路线。
- 在手机上检查点击区域和文字，在手柄上检查选项焦点。
- 选项出现前后，玩家不能通过普通下一句意外跳过选择。
- 若选项没有连接后续内容，确认这正是想要的结束行为。

旧版将多条选项用 `\n\n` 拼接、手动设置选项数量和调整 UI 比例的步骤，不适用于这里的 2.x 选项流程。
