# 公共事件

公共事件是模板预设的常用演出行为。在时间轴上添加公共事件片段，再选择事件、填写参数，就能使用，不必为每一次动作重新搭一套节点图。

视频对应：[13:32—16:08](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=812)。

## 内置行为

| 事件 | 用途与注意点 |
| --- | --- |
| 玩家播放技能动画 | 填写技能配置 ID；导入元件或扩展包后要核对本地图中的实际 ID |
| 玩家传送 | 在演出中调整玩家位置／朝向，优先使用模板提供的这条行为 |
| 玩家移动到指定位置 | 指定移动方式和目标位置，用于走到演出站位 |
| 播放简单黑幕 | 用黑幕衔接画面，和显示文字的黑幕对话样式不同 |
| 锁定并播放 BGM | 为当前演出指定音乐，避免区域 BGM 接管 |
| 解锁 BGM | 演出结束后交回区域音乐管理 |
| 演出注目实体／注目镜头 | 使用预设的注目行为；与完整自定义运镜不同 |
| 重置镜头 | 将镜头恢复到模板约定状态 |
| 触发实体朝向 | 对支持的物件调整朝向；视频示例使用带基础运动器的物件 |
| 玩家朝向实体（2.1） | 原神 7.2 / 模板 2.1 新增；需要实际模板节点图支持 |

## 添加一个动作片段

1. 选中需要动作的 Group，在时间轴中添加公共事件。
2. 选择「玩家播放技能动画」，从预设选择技能，或填写本地图内的技能配置 ID。
3. 将 Clip 放到希望动作开始的时刻。例如与对话同时开始，就放在 0 秒。
4. 检查这段对话的推进延迟，避免玩家点击后过早进入下一组。
5. 导出、更新游戏变量并试玩。

事件的参数按类型填写：GUID、配置 ID、实体注册表键名不是同一种值。用实体预设或技能预设选择参数后，也要确认对应资源已存在于游戏地图中。

## 技能扩展包与版本

2.1 补充了 7.2 技能动画。旧模板导入扩展包后，需要在工作区设置中勾选对应扩展包，并重新读取本地图的 GIL 校验技能 ID。新 2.1 模板已自带这些动作。

扩展包只补资源，不会把 2.0 的节点图升级成 2.1。例如「玩家朝向实体」涉及新的节点图逻辑，不能只通过安装动作包或切换网页版本获得。

坐下相关动作在新版中会继续衔接较长的坐下持续动画和后摇。需要精确收尾时，应检查实际技能的播放表现和后续演出安排。

## 自己扩展公共事件

网页「预设 → 公共事件」可以增加事件名、参数和持续时间设置，但游戏内也要实现对应的接收与执行逻辑。只在网页添加条目不会自动创建节点图。

2.1 增加「是否可拖拽 Clip 边缘」设置：启用后可以拖动片段两侧调整长度。片段长度是否对应游戏中的行为持续时间，仍由事件自身的参数和实现决定。

单个项目专用、无需做成预设的行为，可直接使用[自定义事件](./节点图事件触发.md)。
