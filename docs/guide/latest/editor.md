# 模版与编辑器使用入门

这份模板主要使用 [网页编辑器](https://tool.xiaomol444.xyz/DSFGStudio) 编写内容，以更加可视化的方式修改内容，未来会给网页加上MCP，可以自行让AI操作编辑器

一切的对话、任务、场景管理、镜头，都可以在这里编辑，然后下载对应的结构体变量Json文件，导入进千星奇域中

## 创建工作区

1. 在左上角点击「＋」，为当前奇域新建工作区。

::: info 工作区
一个工作区即对应一个存档
:::

2. 选择实际使用的项目文件类型。地图版和两种元件版分别对应三个选项。
3. 按模板版本选基准。（可以在复合节点中搜索「**[info]当前模版信息**」查看下载模版的版本）
4. 特别的，当文件类型为元件版的时候，需要按提示选择导入自己导入模版后的地图存档，用以校验结构体索引和技能配置 ID。已有工作区可以用名称旁的「… → 工作区设置 → 读取 GIL」重新识别，检查结果并保存。

![工作区设置中的项目类型、基准版本和 GIL 工具](/images/tutorial-v2/workspace-settings-current.jpg)

## 先改一句台词

在「对话 → 演出对话」新建「城门口的向导」，按[文本编辑](./dialogue/performance/text-editing.md)做两句台词。向导先说「你终于到了」，然后说「我们去城门看看吧」。网页会把编辑内容保存在工作区中。点击「导出千星演出」后，才得到可以导入游戏的运行时 JSON。

## 把导出的演出放进奇域 {#try-in-game}

1. 点击「导出千星演出」，下载当前文件的运行时 `.json`。
2. 在游戏场景中准备一个**动态实体**，作为这段演出的数据载体。它可以是 NPC，也可以是专门承载剧情数据的逻辑实体。
3. 打开「组件 → 自定义变量 → 详细编辑」。
4. 新建结构体变量，类型选择模板中的 `[演出]演出`，变量名设为「城门口的向导」。
5. 在变量的结构体编辑界面中导入刚下载的 JSON，确认出现 ActionGroup、DialogueData 等演出数据并保存。

![游戏中的演出结构体变量](/images/tutorial-v2/import-performance.jpg)

*图：视频 [08:06](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=486)，把网页导出的运行时数据导入演出变量。*

::: warning 校对结构体 ID
元件导入后，结构体 ID 可能与编辑器默认值不同。遇到结构体不匹配时，先回工作区设置读取自己的 GIL 并校对，不要直接照抄其他地图的编号。
:::

## 首次接入时触发演出

示例使用实体的交互选项卡：

1. 给数据实体添加「选项卡」组件，并配置一条可互动的选项。
2. 在该实体上挂载节点图，使用「选项卡选中时」作为入口。
3. 将「选择者实体」传入「获取角色归属的玩家实体」。
4. 接上复合节点 `[演出]播放演出`。
5. 「玩家实体」填上一步得到的玩家；「目标实体」填存储演出变量的实体；「变量名」填「城门口的向导」。

![选项卡选中后播放目标实体上的演出变量](/images/tutorial-v2/trigger-performance.jpg)

*图：视频 [08:23](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=503)。*

这里有三个容易混淆的名字：**网页文件名**用于管理工程，**实体上的变量名**用于读取数据，**节点输入的变量名**必须与实体上的变量名一致。

节点图可以挂在其他实体上，但「目标实体」必须指向真正保存演出变量的实体。不要把玩家实体、角色实体和数据实体接反。

与 NPC 互动的选项卡，也不同于剧情中让玩家选回答的动态选项卡。后者见[选项卡](./dialogue/performance/choices.md)。如果演出时仍显示场景交互选项，请参考模板示例给交互项配置对话期间隐藏的过滤逻辑。

## 修改后重新试玩

与向导互动，确认第一句出现，按下一句后进入第二句，最后结束演出并恢复操作。把第二句改成「请先到城门集合」，再次导出 JSON，导入**同一个**演出变量并重试。看到新台词就说明游戏已用上新数据。只改内容时可以继续使用第一次接好的播放节点。

以后做动作、选项或镜头，也可以按这个流程更新演出变量。各模块的专用结构体和接线见对应教程。
