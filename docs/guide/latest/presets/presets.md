# 预设

打开编辑器的「预设」。这里的配置由当前工作区共用，比如同一个向导可以用于多段台词，同一个技能配置 ID 可以用于多处演出。

系统条目的名称固定，实际值可按地图调整；自定义条目可以新增或删除。引用时要看字段的规则。比如从实体预设填入说话人，或从技能预设选一个 ID 时，已有台词和片段会保留选中时的值。改了预设后，想更新已有片段就到原片段重新选一次。

| 要配置什么 | 从哪里开始 |
| --- | --- |
| 常用 NPC、GUID 或实体查询键名 | [实体与引用](./entities.md) |
| 台词、选项卡等的显示方式 | [样式与参数](./styles.md) |
| 公共事件参数、技能动画或相机名称 | [事件、技能与相机](./events-and-assets.md) |
| 给多个事件提供可以复用的参数记录 | [自定义配置](./custom-config.md) |

## 多语言文本管理 {#multilingual-text}

在「预设 → 其他 → 多语言文本管理」下载模板的简体中文或全语言 CSV。回到千星沙箱，打开「多文本管理（脚本变量）」并导入。已有语言文件时先导出备份，把模板所需的条目合并进去再导入。试玩检查自动播放、历史和隐藏 UI 等按钮是否显示正确文字。

[2.0 视频 06:30](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=390)演示了下载和导入，截图中的入口是录制时的布局。

超限模式地图版的「预设 → 其他 → 存档模块」用于查看和标记数据位段。配置示例见[存档](../save.md#save-modules)。
