# 事件、技能与相机

这些预设提供时间轴里可选择的事件和资源名称。先在当前工作区校对，再到演出片段选择。

## 公共事件参数

在「预设 → 公共事件」选择现有事件或新建条目，填写事件名，按游戏节点图接收的参数定义类型、默认值和所需的值来源。选了实体 GUID 作为值来源，片段里就能从实体记录取值。2.1 增加「是否可拖拽 Clip 边缘」，可以按[事件片段的时间设置](../public-events/public-events.md#event-timing)检查效果。

自定义事件名和参数需要对应游戏内已有的执行逻辑。接线和试玩方法见[添加自定义公共事件](../public-events/public-events.md#custom-events)。

## 技能动画

在「预设 → 技能动画」校对显示名称与游戏技能配置 ID。旧模板导入 7.2 扩展包后，按[使用 7.2 技能动画](../public-events/public-events.md#skill-expansion)重新识别 ID。保存后，已有片段仍使用此前选中的 ID，需重新选择才能更新。

## 相机

在「预设 → 相机」配置用于选择的显示名称和地图里的实际相机名称。比如把工作区条目命名为「城门近景」，值填地图中对应的镜头名称。再到[运镜](../camera/camera.md)选该条目，检查游戏调用的是哪台相机。机位、视点和移动方式在镜头片段内设置。
