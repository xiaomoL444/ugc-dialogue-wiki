# 样式与参数

在「预设」里选择对应分类。演出对话的「对话类型」控制台词的显示方式，「选项卡样式」控制玩家选择界面，「边走边说类型」用于探索中的消息。超限模式地图版工作区还提供「任务样式」。

## 用同一句台词比较样式

在[文本编辑](../dialogue/performance/text-editing.md)中，把「你终于到了」先设成默认样式，再换成底部 CG 文本。检查位置、说话人和副标题的显示差别。对话类型启用「显示标题」时会显示人名与副标题；关闭后导出不带这两个字段的内容，工程中填写的文字仍会保留。

## 自定义样式参数

自定义样式填写游戏脚本可识别的类型值。对话和选项卡的样式参数按定义的顺序传入整数，调整顺序前应核对客户端脚本读取的是哪一项。要验证一种新样式，可以只在一条测试台词或一个选项卡上使用它，再进游戏核对显示和操作。

网页预设提供编辑和导出的候选值。游戏中的画面由模板客户端样式实现。已有样式的效果和选用方法见[文本编辑](../dialogue/performance/text-editing.md#styles)。
