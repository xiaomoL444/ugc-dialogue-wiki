# 实体与引用

在「预设 → 实体」新建人物，例如「城门口的向导」。填写说话人「向导」，需要额外显示身份时再填写副标题。然后到「演出对话 → 文本编辑」，点台词旁的头像或代号，选刚建的条目。台词内容保留，说话人和副标题更新为选中的值。

| 字段 | 填什么 | 在哪里用 |
| --- | --- | --- |
| 说话人、副标题 | 游戏里显示的人名与身份 | 台词和支持这些字段的事件参数 |
| GUID | 地图里对应实体的 GUID | 固定实体的位置、朝向或镜头引用 |
| 实体查询 | 游戏节点图注册实体时用的键名 | 运行中生成或需要按键名查询的实体 |

两个实体引用字段按实际用途填写。需要按键名查询时，先在游戏里完成[实体注册](../camera/entity-registry.md)。如果同一个名字的 NPC 已经换成另一实体，核对 GUID 或注册键名是否指向新对象，并重新选择已有片段使用的预设。
