# 自定义配置

当多个公共事件反复使用同一批参数，可以在「预设 → 自定义配置」创建类别、字段和记录。

例如几个演出都要查询城门机关，可以新建「机关」类别，再加一个 String 类型的「注册键名」字段。创建「城门」和「侧门」两条记录，分别填写游戏中注册的键名。

1. 在公共事件预设里，给接收键名的 String 参数选「机关 → 注册键名」作为值来源。
2. 回到时间轴选中该事件片段，在参数下拉中选择「城门」。
3. 试玩确认事件作用到城门。改选「侧门」后，再确认效果落到另一个对象。

选中记录会把字段值复制到片段。修改记录后，要更新已有片段就重新选择一次。配置值来源时，字段类型要与参数类型匹配。游戏节点图仍需要能按这个键名找到实体并执行相应逻辑。
