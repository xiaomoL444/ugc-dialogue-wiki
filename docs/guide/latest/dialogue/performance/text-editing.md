# 文本编辑（流式编写）

用「城门口的向导」做两句站桩对话。先在工作区内新建一份演出，默认会打开「文本编辑」。2.0 视频从 [06:51](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=411) 开始演示。

## 写两句台词

在文本视图中添加默认对话，填写说话人「向导」、台词「你终于到了」。副标题可以填「城门守卫」，也可以留空。样式先选「默认」。再添加「我们去城门看看吧」，把第一句的出口连到第二句，确认「开始」连着第一段。

![在文本视图中填写台词并选择样式](/images/tutorial-v2/dialogue-editor.jpg)

*图：2.0 视频 [07:49](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=469)。*

先保留「玩家按下」，试玩时应能依次看到两句台词。通用导出和接入步骤见[编辑器入门](../../editor.md#try-in-game)。

## 对话样式与参数 {#styles}

| 内置样式 | 用途 |
| --- | --- |
| 默认样式 `NOLOC_Default` | 常规人物对话 |
| 黑幕对话 `NOLOC_BlackScreen` | 在黑幕上显示文字 |
| 底部 CG 文本 `NOLOC_BottomCG` | 画面底部的字幕式文本 |
| 底部对话文本 `NOLOC_BottomDialog` | 底部显示的人物对话 |
| 清除效果 `NOLOC_Clear` | 清除当前对话表现，用于不同演出内容的衔接 |

样式决定显示效果，不等同于整个 Group 的推进方式。黑幕是否等待点击、何时切换下一段，需要在[时间轴与推进](./timeline/progression.md)中设置。

自定义样式及其整数参数由[预设](../../presets/styles.md)与客户端样式脚本共同约定。仅在网页添加一个样式名字，并不会自动给游戏增加相应 UI。

## 动态文本与实体预设

[「预设 → 实体」](../../presets/entities.md)可以记录常用说话人的名字、副标题、GUID 和实体注册表键名，填写台词或公共事件时从预设中选择，减少反复输入。

文本支持读取自定义变量，例如 `{1:ps.NICKNAME}` 表示玩家自身的 `NICKNAME` 变量。`ps`、`lv`、`as` 分别对应玩家自身、关卡和当前角色。变量名必须真实存在，类型与用途要一致；先用普通文本确认流程，再替换为动态内容。

想让玩家选回答，继续看[选项卡](./choices.md)。想调整台词和动作的时机，切到[节点编辑与时间轴](./timeline/timeline.md)。
