# 条件分支与合流

用条件分支让演出按变量状态走不同路线。比如向导看到玩家已经取得钥匙，就说「城门可以打开了」；玩家还没拿到钥匙时，提示去找守卫。

1. 在奇域里准备记录钥匙状态的变量，确定它属于玩家、角色还是关卡。
2. 在演出对话中添加「条件分支」，选对变量并设定条件。
3. 把满足条件的出口连到「城门可以打开了」，把另一条路线连到「先去找守卫」。
4. 两条路线需要继续同一段剧情时，把各自的出口接到同一个后续 Group。

试玩分别检查有钥匙和无钥匙的结果，以及合流是否正确。多人地图还要检查每个玩家是否按自己的状态走对应路线。台词中的变量占位符用于显示；分支条件在条件节点里配置。

由玩家点哪项来决定走向时，用[选项卡](./choices.md)。由计时器在指定时刻推进时，用[强制跳过](./timeline/progression.md)。
