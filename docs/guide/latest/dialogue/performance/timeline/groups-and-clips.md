# Group、轨道与片段

## Group、轨道与 Clip

- **Group**：流程图中的一个演出组。进入后，开始运行它自己的时间轴。
- **轨道**：把对话、选项、公共事件、镜头等行为分行管理。
- **Clip**：轨道上的一段行为。它的位置表示开始时间，属性决定行为内容；可调长度的片段还包含持续时间。
- **出口**：决定如何进入下一组。出口来自玩家按下、选项选择或强制推进等行为。

多个轨道可以在同一时间发生行为。例如显示台词的同时播放动作，过一秒再切镜头。把片段放在时间轴上，比旧版按句子序号填写事件字典更直观。

## 片段时机与播放顺序

| 设置 | 控制什么 |
| --- | --- |
| 片段开始时间 | 进入当前 Group 后，多久触发该 Clip |
| 片段持续时间 | 该行为维持多久，是否可调整取决于片段类型 |
| 对话推进延迟 | 对话出现后，多久允许按下推进；不是 Clip 在时间轴上的起点 |
| 自动推进等待时间 | 玩家开启自动播放时，等待多久进入下一段 |

自动播放是工具栏中的播放状态。若剧情要求无论玩家是否开启自动播放都在指定时刻切换，应使用强制跳过片段，而不是只改自动播放等待时间。

## 一个简单编排示例

| Group 内时间 | 行为 |
| --- | --- |
| 0 秒 | 显示「你终于到了」 |
| 0 秒 | 公共事件：播放技能动画 |
| 1 秒 | 公共事件或镜头片段：切换镜头 |
| 2 秒以后 | 允许玩家按下一句 |

这里的数值只是制作示例，不是模板固定值。先用两三个片段确认时序，再逐步增加行为。

## 清除画面与收尾

切换到只有动作或其他表现的 Group 时，前一句对话可能仍需要主动清除。可以使用对话中的「清除效果」样式安排衔接。

“清除当前对话表现”“重置镜头”“结束整个演出”是不同操作。不要仅用隐藏 UI 代替流程结束，也不要以为触发一个公共事件就会自动进入下一 Group。

需要选择下一组时，看[推进与强制跳过](./progression.md)。片段的详细设置见[公共事件](../../../public-events/public-events.md)和[运镜](../../../camera/camera.md)。
