# 推进与强制跳过

每个 Group 的出口决定下一段去哪里。用「城门口的向导」的第一句分别测试下列设置。

| 推进方式 | 怎么设 | 试玩时会怎样 |
| --- | --- | --- |
| 玩家按下 | 对话设为「玩家按下」，把出口连到下一组 | 玩家点下一句后才进入第二句 |
| 玩家选择 | 添加选项卡，给每个选项连接后续组 | 玩家选哪项，就走对应路线 |
| 强制跳过（共用出口） | 在指定时间放强制跳过片段，选择已有出口 | 时间到了就使用所选出口 |
| 强制跳过（独立出口） | 添加强制跳过片段，把它自己的出口连到目标组 | 时间到了走这条独立路线 |

对话设为「不触发按下」后，由选项或强制跳过接管推进。自动播放还受工具栏开关和等待时间影响。剧情要求定时切换时，使用强制跳过。

## 试做两秒黑幕

在一个 Group 放入黑幕对话，把它设为「不触发按下」。在第 2 秒添加一个独立出口的强制跳过，连到向导出现的 Group。试玩时，黑幕停留约两秒后进入向导的台词。再用同一段测试共用出口，确认定时触发后进入的是你选中的路线。

如果卡在某个 Group，先检查它由什么触发推进，再检查出口连到哪里。想用不同的回答推进，见[选项卡](../choices.md)。
