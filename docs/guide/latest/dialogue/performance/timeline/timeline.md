# 节点编辑与时间轴

在「节点编辑」里，连线决定下一步走到哪个 Group。选中一个 Group 后，下方时间轴决定进入这一组之后，各个片段什么时候发生。

用「城门口的向导」做实验。在同一个 Group 的第 0 秒显示「你终于到了」，第 1 秒让向导转身。如果希望动作播完再允许继续，检查对话推进延迟，或给动作单独建一个 Group。

- [Group、轨道与片段](./groups-and-clips.md)讲怎样安排台词、动作和镜头。
- [推进与强制跳过](./progression.md)讲点击、选项、定时切换各走哪个出口。
- [节点图事件触发](./node-events.md)讲怎样在演出指定时刻让游戏节点图开门。

要配置动作或镜头的具体参数，分别看[公共事件](../../../public-events/public-events.md)和[运镜](../../../camera/camera.md)。
