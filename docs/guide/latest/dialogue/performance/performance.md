# 演出对话（站桩对话）

在网页编辑器打开「对话 → 演出对话」，新建「城门口的向导」。默认打开「文本编辑」；切到「节点编辑」后，选中一个 Group 就能打开该组的时间轴。两种视图共享同一份演出。

1. 在[文本编辑](./text-editing.md)里写两句台词，先确认按下一句能正常接到第二句。
2. 需要玩家选路线时，加入[选项卡](./choices.md)。需要按任务或变量状态走不同路线时，配置[条件分支与合流](./branches.md)。
3. 需要安排字幕、动作或镜头的出现时机时，进入[节点编辑与时间轴](./timeline/timeline.md)。

修改后按[编辑器入门](../../editor.md#try-in-game)的步骤更新游戏内数据。首次接入时还需要用播放节点触发这份演出。

2.0 视频从 [06:51](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=411) 开始演示创建、导出和触发对话，从 [10:36](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=636) 开始讲时间轴。
