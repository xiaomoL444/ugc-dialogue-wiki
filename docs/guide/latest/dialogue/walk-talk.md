# 边走边说

边走边说属于消息文本：玩家可以继续移动，台词按顺序自动播放。它有独立的数据和播放入口。

视频对应：[20:51—21:45](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=1251)。

## 编写与导出

1. 在网页编辑器选择「对话 → 边走边说」。
2. 新建文件，按顺序添加台词。
3. 为每句填写样式、说话人、副标题、内容和推进延迟。
4. 点击「导出千星边走边说」，下载运行时 JSON。
5. 在游戏的数据实体上创建 `[消息]边走边说对话列表结构体` 类型的自定义变量，导入 JSON。

## 触发播放

在游戏节点图中使用「消息播放边走边说对话」相关复合节点，传入目标玩家、保存数据的实体及变量名。

入口可以是选项卡、碰撞器或自己的事件。示例从交互选项卡触发；换成区域触发时，仍然要正确取得进入区域的玩家。

## 推进时间如何理解

消息中的「推进延迟」决定多久自动进入下一句。它不等待演出对话的「玩家按下」出口，也不需要玩家先打开工具栏中的自动播放。

例如三句台词分别显示 3 秒、2 秒、4 秒，就按这个顺序配置对应的时间。先用较长时间检查文字是否完整，再按剧情节奏缩短。

一份边走边说列表最多 100 句。长剧情可以拆分文件并通过节点图分段触发。重复进入碰撞器可能重复播放，是否只播放一次应由自己的触发条件控制。

## 与演出对话的选择

需要玩家停下、选择回答、配合完整镜头和演出事件时，使用[演出对话](./performance/performance.md)。只需在行走或探索途中显示一段自动字幕，使用本页的消息流程更直接。
