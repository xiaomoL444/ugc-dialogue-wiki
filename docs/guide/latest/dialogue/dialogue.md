# 对话

网页编辑器的「对话」有两个入口。想让玩家停下和 NPC 聊几句，可以选「演出对话」。想让 NPC 在玩家探索时继续说话，可以选「边走边说」。

| 类型 | 玩家看到的效果 | 操作入口 |
| --- | --- | --- |
| 演出对话 | 按下一句、选回答，台词可与动作或镜头配合 | [演出对话（站桩对话）](./performance/performance.md) |
| 边走边说 | 台词按延迟自动播放，玩家可以继续行动 | [边走边说](./walk-talk.md) |

第一次做演出可以用一个最小例子。向导先说「你终于到了」，玩家按下一句后看到「我们去城门看看吧」。先把这两句接起来，再添加选项或镜头。
