# 实体注册表

引用地图中已有实体可直接填写 GUID。需要通过字符串找到动态生成的实体时，用总控实体注册表保存「键名 → 实体」的对应关系。

1. 在游戏节点图里取得实际的实体，在演出开始前调用「注册实体」，填写键名。
2. 在网页编辑器选 `NOLOC_Entity`，填入相同的键名。
3. 确认镜头触发时实体已经生成、完成注册，而且还在场景中。实体销毁或之后不再使用时，可调用「注销实体」。

例如把城门向导注册为 `city_gate_guide`，在视点设置里引用该键。编辑器中的名字可以存成实体预设，实际绑定由节点图完成。

![用节点图把实体登记到注册表键名](/images/tutorial-v2/camera-registry.jpg)

键名在游戏里对应哪个实体，单靠实机画面看不出来。想看使用不同目标时的画面变化，见[镜头目标与实体绑定的效果演示](./targets.md#效果演示)。
