# 独立镜头与复用

只在一段对话里使用的镜头，可以直接在 Group 的相机轨道里配置。需要从其他事件单独触发时，可以做成独立镜头文件。

1. 在网页编辑器的「镜头」入口新建文件，选择相机预设，配置机位、视点和时长。
2. 导出镜头数据。按视频示例，把运镜参数填进目标实体的自定义结构体变量。
3. 在游戏节点图中使用模板的「写入运镜参数」和触发运镜节点，传入对应镜头。试玩确认它在预期事件触发时播放。

![独立镜头编辑页，左边是镜头文件列表，中间是相机设置，右上方可填写时长并导出千星镜头](/assets/camera/standalone-settings.jpg)

完整的运镜画面可见[镜头组合与实机对照](./movement.md#效果演示)。
