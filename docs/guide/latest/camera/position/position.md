# 机位位置

「相机位置」决定镜头从哪里拍。先确定机位，再去[视点位置](../viewpoint/viewpoint.md)设置镜头朝哪边看。比较机位方式时，可以先保留同一个视点，观察主体的大小和背景怎么变。

| 机位方式 | 画面效果 |
| --- | --- |
| [固定位置](./fixed.md) | 镜头停在指定位置 |
| [线性移动](./linear.md) | 机位从起点移动到终点 |
| [跟随](./follow.md) | 机位跟着参考实体走，可设置偏移 |
| [环绕](./orbit.md) | 机位围着参考点走圆弧 |

坐标、GUID 和实体键名的区别见[镜头目标与实体绑定](../targets.md)。
