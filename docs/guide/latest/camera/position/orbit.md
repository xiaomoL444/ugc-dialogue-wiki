# 机位 · 环绕

相机沿参考点周围移动，适合在对话中展示角色的不同拍摄角度。

1. 在「相机位置」选「环绕」，选一个环绕中心并填写「环绕半径」。
2. 填写「初始环绕角度」和「结束环绕角度」。视频用 Y 轴演示水平环绕，垂直方向用 Z 轴。
3. 想让被拍对象一直留在画面里，可以在[固定视点位置](../viewpoint/look-at.md)引用同一个实体。试玩时检查镜头经过的位置会不会被场景物件挡住。
