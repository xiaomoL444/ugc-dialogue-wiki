# 视点 · 线性移动

镜头跟着变化的视点转向。例如让视线从角色移到角色头顶的标记。相机本身从哪拍，由[机位位置](../position/position.md)单独决定。

1. 打开「配置视点位置」，选「线性移动」。
2. 设置视点终点。需要固定第一次看向的位置时，再填起点。
3. 省略起点时，模板取当前视点作为起点。试玩时观察视线是否在预定时间内移到终点。

![视点位置选中线性移动，右侧显示视点的起点和终点](/assets/camera/viewpoint-linear-settings.jpg)
