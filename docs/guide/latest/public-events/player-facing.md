## 事件参数

| 参数名 | 参数类型 | 参数作用 |
| --- | --- | --- |
| 是否是朝向说话人 | 布尔值 | 选「是」时朝向当前说话人，选「否」时使用下方指定的实体。默认「是」。 |
| 实体获取方式 | 整数 | 选择用 GUID（0）或 String（1）查找目标。关闭「是否是朝向说话人」时显示。 |
| GUID | GUID | 目标实体的 GUID。关闭「是否是朝向说话人」且获取方式为 GUID 时显示。 |
| String | 字符串 | 目标实体在实体注册表中的键名。关闭「是否是朝向说话人」且获取方式为 String 时显示。 |

## 事件功能

这个事件从模板 2.1（原神 7.2 基准）起可用，需要地图里的对应节点图。

| 「是否是朝向说话人」 | 设置方式 | 试玩效果 |
| --- | --- | --- |
| 是 | 使用当前说话人 | 玩家朝向对话中的人物 |
| 否 | 选择实体获取方式，填写 GUID 或已注册的 String 键名 | 玩家朝向所指定的实体 |

先让向导说话时触发一次，再把目标换成城门，比较玩家的朝向。旧项目可以到[版本与升级](../upgrade.md)核对支持范围。
