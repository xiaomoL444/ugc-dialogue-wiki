# 设置实体预设状态（v7.3）

## 效果演示

## 事件片段

<!-- ![设置实体预设状态的时间轴片段和参数面板](/assets/public-event/set-preset-status/view.png) -->

| 事件别名 | 事件名 |
| --- | --- |
| 设置实体预设状态（v7.3） | NOLOC_SetPresetStatus |

## 事件参数

| 参数名 | 参数类型 | 参数作用 |
| --- | --- | --- |
| 实体获取方式 | 整数 | 选择用 GUID（0）或 String（1）查找目标实体。默认 GUID。 |
| GUID | GUID | 目标实体的 GUID。获取方式为 GUID 时显示，从实体预设中选择。 |
| String | 字符串 | 目标实体在实体注册表中的键名。获取方式为 String 时显示，从实体预设中选择。 |
| 预设状态索引 | 整数 | 填写目标实体上要修改的预设状态索引。默认 0。 |
| 预设状态值 | 整数 | 填写要写入该预设状态的值。默认 0，具体含义按目标实体的配置填写。 |

## 事件功能

这个事件从原神 v7.3 基准起可选。演出播到片段的开始时间时，模板会按指定索引设置目标实体的预设状态。

例如，想让向导说完话后切换城门的状态，可以把这个片段放在台词之后，选择城门，再填写城门上对应的状态索引和状态值。试玩时检查城门是否在指定时刻切换到了预期状态。

需要按 String 查找实体时，请先在游戏节点图中注册对应键名。网页里的配置见[实体与引用](../presets/entities.md)。
