## 事件参数

| 参数名 | 参数类型 | 参数作用 |
| --- | --- | --- |
| 设置朝向（否＝重置） | 布尔值 | 选「是」时让实体 1 朝向实体 2，选「否」时重置实体 1 的朝向。 |
| 实体1获取方式 | 整数 | 选择用 GUID（0）或 String（1）查找要转动或重置的物件。 |
| 实体1 GUID | GUID | 要转动或重置的物件 GUID。实体 1 的获取方式为 GUID 时显示。 |
| 实体1 String | 字符串 | 要转动或重置的物件在实体注册表中的键名。实体 1 的获取方式为 String 时显示。 |
| 实体2获取方式 | 整数 | 选择用 GUID（0）或 String（1）查找朝向目标。开启「设置朝向」时显示。 |
| 实体2 GUID | GUID | 朝向目标的 GUID。开启「设置朝向」且实体 2 的获取方式为 GUID 时显示。 |
| 实体2 String | 字符串 | 朝向目标在实体注册表中的键名。开启「设置朝向」且实体 2 的获取方式为 String 时显示。 |

## 事件功能

用这个事件让有相应运动器的物件朝向另一个实体。比如让城门旁的路标在向导说话时转向入口。

1. 「设置朝向」选「是」，为实体 1 选择要转动的物件，为实体 2 选择朝向目标。
2. 两个实体各自选择 GUID 或 String。用 String 时，填写已在节点图中注册的键名。参见[实体与引用](../presets/entities.md)。
3. 想在收尾恢复朝向时，再放一个片段，把「设置朝向」设为「否」，选中同一个实体 1。

试玩时分别检查物件转向和重置的效果。目标找不到时，核对引用值和物件的运动器。
