## 事件参数

该事件没有参数。

## 事件功能

在向导出场的 Group 加入「演出注目实体」。内置预设没有参数，具体注目对象由所用模板的演出逻辑决定。试玩时观察画面是否转向预期对象。

需要指定不同的机位、视点或跟随方式时，使用[运镜](../camera/camera.md)配置镜头片段。演出收尾可以加[重置镜头](./reset-camera.md)。
