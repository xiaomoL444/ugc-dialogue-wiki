## 事件参数

| 参数名 | 参数类型 | 参数作用 |
| --- | --- | --- |
| 设置位置 | 布尔值 | 选「是」时按下方 X、Y、Z 调整玩家位置，选「否」时保留当前位置。 |
| 位置 X | 浮点数 | 目标位置的 X 坐标。开启「设置位置」时显示。 |
| 位置 Y | 浮点数 | 目标位置的 Y 坐标。开启「设置位置」时显示。 |
| 位置 Z | 浮点数 | 目标位置的 Z 坐标。开启「设置位置」时显示。 |
| 设置旋转 | 布尔值 | 选「是」时按「旋转 Y」调整玩家朝向，选「否」时保留当前朝向。 |
| 旋转 Y | 浮点数 | 玩家的目标 Y 轴旋转角度。开启「设置旋转」时显示。 |

## 事件功能

用这个事件把玩家切换到下一段演出的站位。

| 开关 | 开启时填写 | 试玩效果 |
| --- | --- | --- |
| 设置位置 | 目标位置的 X、Y、Z | 玩家传送到指定位置 |
| 设置旋转 | 旋转 Y | 玩家转向指定角度 |

例如从城门外切到门内时，同时开启位置和旋转。只想在原地调整朝向时，关闭位置，只设置旋转。试玩确认落点和朝向，避免把玩家放在墙里或悬空的位置。
