# 解锁 BGM（v7.1）

## 效果演示

## 事件片段

<!-- ![解锁 BGM的时间轴片段和参数面板](/assets/public-event/unlock-bgm/view.png) -->

| 事件别名 | 事件名 |
| --- | --- |
| 解锁BGM（v7.1） | NOLOC_UnlockBGM |

## 事件参数

该事件没有参数。

## 事件功能

把这个事件放在演出收尾的时间轴上。模板内置预设没有参数。触发后解除演出音乐的锁定，让区域音乐管理可以重新接管。

可以先用[锁定并播放 BGM](./lock-and-play-bgm.md)切到演出音乐，再触发解锁并检查当前区域的音乐表现。试听时确认收尾 Group 确实有执行到这个片段。
