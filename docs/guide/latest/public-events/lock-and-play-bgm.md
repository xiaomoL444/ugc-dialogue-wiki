| 事件别名 | 事件名 |
| --- | --- |

## 事件参数

| 参数名 | 参数类型 | 参数作用 |
| --- | --- | --- |
| 背景音乐索引 | 整数 | 填写要播放的背景音乐索引。 |
| 开始时间 | 浮点数 | 音乐从曲目的第几秒开始播放，默认 0 秒。 |
| 结束时间 | 浮点数 | 指定曲目的播放结束位置，默认 999 秒。 |
| 播放速度 | 浮点数 | 音乐的播放速度，默认 1 倍。 |

## 事件功能

填入地图里的「背景音乐索引」，按需要设置音乐的开始时间、结束时间和播放速度。时间轴上片段的开始时间决定**什么时候触发播放**，事件里的开始时间决定**从音乐哪一段开始**。

比如在向导出场时切到演出音乐。试玩时进入有区域 BGM 的地点，检查演出音乐在锁定期间是否继续播放，再用[解锁 BGM](./unlock-bgm.md)把音乐管理交回区域。
