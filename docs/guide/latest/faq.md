# 常见问题

先确认模板版本和项目文件类型，再对照症状检查。2.x 的导入流程见[下载与导入](./download/download.md)，2.0 → 2.1 的修复边界见[版本与升级](./upgrade.md)。

## 播放后完全没有 UI

依次检查：

1. 目标玩家是否使用演出玩家模板，相关变量和节点图是否完整。
2. `[演出]播放演出` 的目标实体是否真的保存了演出数据，变量名是否一致。
3. 传入的是玩家实体，还是尚未转换的角色实体。
4. 元件版是否已修复 UI 索引，并导入多语言文本。
5. 导出 JSON 的结构体 ID 是否对应当前地图。
6. 管理实体是否因运行范围设置停止执行。

如果是在传送或死亡后才消失，另看下方 UI 重建问题。

## 网页改了台词，游戏中还是旧内容

网页保存不会直接写回游戏。重新「导出千星演出」，把 JSON 导入当前正在读取的实体变量，再重新试玩。也要确认没有改到另一个工作区、另一个实体或同名变量。

## 无法进入下一句／选项后卡住

检查当前 Group 是否提供了出口、出口是否连接正确。只有对话显示不代表一定配置了推进。

对话设为「不触发按下」时，需要由选项或强制推进等行为接管；对话与选项同时请求推进时，按编辑器提示排除冲突。详见[时间轴](./dialogue/performance/timeline/progression.md)。

## 自动播放与定时切换不一致

工具栏自动播放需要玩家开启，并使用自动推进等待时间。剧情要求按固定时间切换时，使用 Focus Push 强制跳过。边走边说则使用自己的推进延迟，三者不是同一套时间设置。

## 按钮显示键名、空白或不正常文字

元件版需要导入模板的多语言文本。自动修复 UI 索引不会补上语言文件；已有语言内容要合并后导入。步骤见[多语言文本管理](./presets/presets.md#multilingual-text)。

## 移动端自动播放、历史、隐藏按钮不能点击

旧版存在客户端脚本问题，按[2.1 脚本更新方法](./upgrade.md)更新。更新后仍异常时，检查 UI 索引以及自己的控件是否遮挡点击区域。

## 传送、死亡后对话消失或鼠标无法关闭

覆盖新版脚本只修复其中一部分。UI 重新显示还依赖 2.1 节点图的重建逻辑；2.0 项目优先使用公共事件的玩家传送，并避免演出期间触发意外传送或死亡。不要通过重新显示一个控件来代替完整 UI 重建。

## 技能动作不在列表里，或播放了别的动作

检查是否安装了对应扩展包、工作区是否启用它，以及技能配置 ID 是否从当前地图 GIL 校对。动作资源的导入与模板节点图升级是两件事。

## 镜头不到位、固定位置无效

先检查镜头模板名、GUID／实体注册表键名、机位与视点开关。2.0 固定位置镜头还有已知节点图问题，需要按[升级说明](./upgrade.md)修复。经典模式同时受玩家镜头数据限制。

## 实体字符串查询找不到对象

网页「实体预设」不负责注册游戏实体。用游戏里的注册实体节点登记实际对象，并核对玩家模板上的实体注册表字典值类型是否为「实体」。

## 任务不出现、进度不变或不接后续任务

确认使用的是地图版；再检查任务配置是否导入、任务是否已接取、是否为隐藏任务、单位状态配置 ID 是否正确，以及完成条件是否真的执行。后续关联填写完整子任务 ID，任务进度的含义由玩法逻辑约定。

## 任务距离或区域提示不对

核对任务的调查点和所属一级区域，检查游戏内是否正确切换二级区域。跨世界任务还要建立世界关联点。详见[场景管理](./scenes.md)。

## 读档后任务恢复了，但门和物件没有恢复

模板没有自动持久化所有实体属性。将需要记录的机关写入游戏数据状态，读档后按状态恢复实体表现。详见[存档功能](./save.md)。
