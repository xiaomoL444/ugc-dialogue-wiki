# 下载与导入

## 三种模板有什么区别

| 模板 | 适合的项目 | 包含的主要内容 |
| --- | --- | --- |
| 超限模式地图版（推荐） | 从0开始制作新地图 | 演出、镜头、技能动作，以及任务、场景、存档和调试模块 | 直接导入 `.gil` 地图存档 |
| 超限模式元件版 | 已有超限模式地图，需要接入演出 | 演出、镜头与技能动作，不包含地图版的任务、场景、存档和调试模块 | 将 `.gia` 资产转存到自己的地图，再完成初始化 |
| 经典模式元件版 | 经典模式地图 | 2.1 已增加经典模式支持；需要获取玩家镜头数据的操作仍受限 | 将经典模式 `.gia` 转存到自己的地图，再完成初始化 |

![2.0 视频中的三种模板功能对比](/images/tutorial-v2/version-comparison.jpg)

## 超限模式地图版

拥有模版所有功能模块。适合刚开始制作奇域并需要完整RPG流程（演出、任务、存档）


[查看下载与导入教程 →](./beyond-save.md)

## 超限模式元件版

由地图版本删改功能得来。

适合在当「你已经有大量功能的存档且不方便导出，仅需要演出功能情况下」导入

::: tip 说明
元件版本不提供任务模块，不应作为**完整的RPG模版**。

因为我认为元件版本应该保持功能的单一，毕竟原先是按照「演出模板」/「对话模板」来做。

只是最近也有人提到为什么元件版没有任务模块，我可能以后会尝试单独发一个「任务模版+场景管理」元件来
:::

它提供演出、镜头与技能动作，但不附带地图版的任务、场景、存档和调试模块。转存资产后，需要应用演出玩家模板、修复 UI 索引并导入多语言文本。（参考元件版本导入教程）

[查看下载与导入教程 →](./beyond-component.md)

## 经典模式元件版

由超限模式元件版本删改而来

经典模式元件版拥有超限模式元件版大部分功能，但由于经典模式自身限制，删除了部分功能：主要涉及获取玩家镜头位置与技能部分

导入后，同样需要完成玩家模板、索引和多语言文本配置（参考元件版本导入教程）

[查看下载与导入教程 →](./classic-component.md)

## 导入前注意

::: warning 已有模板项目先确认版本
不要通过**反复导入**整套模板资产来覆盖更新已有项目，也不要把旧地图的全部数据重新导入新版地图。升级已有模板请先阅读[版本与升级](../upgrade.md)。
:::

完成所选教程中的导入与工作区配置后，继续阅读[编辑器入门](../editor.md)。
