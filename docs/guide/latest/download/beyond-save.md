# 超限模式-地图版

![奇域资产中心的超限模式地图版 v2.1 下载页面](/images/tutorial-v2/beyond-save-asset-center.png)

视频参考：[2.0 完整教程 03:42—04:45](https://www.bilibili.com/video/BV1ZCng6LEKV/?t=222)。

## 1. 下载地图资产

进入[奇域资产中心](https://act.mihoyo.com/ys/prod/ugc/component-store/index.html#/item/1992801772275511296)，下载地图版资产。

## 2. 导入 GIL 地图存档

1. 回到原神中的「我的奇域」，选择「导入存档」，选中该 `.gil`。
2. 打开导入后的模板地图，先试玩现成示例，确认对话、任务等功能能够运行。

试玩示例通过后，继续阅读[编辑器入门](../editor.md)，新建超限模式地图版工作区。
