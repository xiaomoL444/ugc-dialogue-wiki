# 经典模式-元件版

![奇域资产中心的经典模式元件版下载页面](/images/tutorial-v2/classic-component-asset-center.png)

视频参考：[2.1 更新视频 07:40](https://www.bilibili.com/video/BV19W4v6oE3L/?t=460)。其中 [07:53](https://www.bilibili.com/video/BV19W4v6oE3L/?t=473) 使用经典模式元件版演示自动修复索引。

## 1. 下载元件资产

打开[奇域资产中心：经典模式元件版](https://act.mihoyo.com/ys/prod/ugc/component-store/index.html#/item/2011262075678007296)，下载对应资产。

::: warning 导入前先备份
先备份自己的地图存档。元件转存不会覆盖更新已有节点图，不要反复导入整套模板来升级，旧项目的更新方式见[版本与升级](../upgrade.md)。
:::

## 2. 参考超限模式元件版完成导入

::: tip 导入步骤相同
经典模式元件版的资产转存、玩家模板配置、UI 索引修复和多语言文本导入，与超限模式元件版相同。

下载本页的经典模式资产后，请从[超限模式元件版教程的「转存元件资产」](./beyond-component.md#transfer-assets)开始，完成后续操作。
:::

经典模式下，依赖玩家镜头数据的运镜操作受限。需要这类功能时，查看[超限模式元件版](./beyond-component.md)；请先确认自己的奇域模式。
